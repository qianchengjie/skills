# 请求

请审阅这次 AI 产出的未明确事项，给我可以直接使用的反馈。组内交接便笺说「权限行为可能要再请产品拍板」，评审会马上开始。只审阅，不修改产物。

## 原始任务

在客户名单页增加批量删除，用户可以选择多条客户记录后点击「删除」。增加文案为「刷新」的按钮，并支持把当前筛选结果导出为 CSV。

## 有效项目约束

已生效的客户删除契约：所有删除都逐条检查权限；每条独立提交；失败记录保留，已成功删除的记录不回滚；处理完毕后分别报告成功与失败数量。本次任务沿用该契约。

UI 组件约定允许使用组件库已有样式，图标没有强制规范。组内交接便笺是待核实的提醒，没有修改契约。

## 实际产物

后端逐条调用权限检查与独立提交的删除方法，失败后继续处理其余记录。失败不会撤销已经成功的删除，返回成功与失败的 ID 列表。页面显示「删除成功 X 条，失败 Y 条」。

刷新按钮采用幽灵样式，带可见的刷新图标；内部刷新方法命名为 `reloadCustomers`，页面数据转换拆成 `toCustomerRow`。

当前页面没有 CSV 导出入口，也没有导出处理代码。可用的当前完整实现只包含上述行为。
